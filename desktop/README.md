# gpu-spooler desktop

A desktop app for gpu-spooler (Tauri 2, React and TypeScript). It links the `gpu-spooler` crate
directly and reads the same `~/.gpu-spooler` state as `task` and `task tui`. It never runs a daemon
of its own.

**Status:** M1. A live, read-only view of the queue. Logs, GPUs, actions and the menu bar item come next.

## Development

Needs Node 20+ and Rust. From this folder:

```bash
npm install
npm run tauri dev        # the app, with hot reload
npm run build            # typecheck + build the frontend
npm run bindings         # regenerate src/bindings.ts after changing a Rust type the frontend sees
cargo test --manifest-path src-tauri/Cargo.toml
```

`src-tauri` is not a member of the root Cargo workspace and has its own lockfile, so building or
testing the CLI never builds Tauri.

## How it works

- **Watcher:** `src-tauri/src/watch.rs` watches `~/.gpu-spooler` for changes to `tasks.db`, its
  WAL, `daemon.pid` and `hosts.toml`. It also re-reads every 5 s. After each read it sends the
  whole `QueueState` to the window, but only when something changed.
- **Types:** `src/bindings.ts` is generated by tauri-specta from the Rust types. The library's
  `specta` feature adds the derives. Commit the generated file, and don't edit it by hand.
